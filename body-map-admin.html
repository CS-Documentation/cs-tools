Connecting the Google Sheet
  1. Recommended: in the sheet, File → Share → Publish to web, pick the form-responses tab, choose Comma-separated values (.csv), press Publish, and paste that link below.
  2. Or paste the normal sheet link, provided it's shared as Anyone with the link → Viewer.

Anyone who can open this link can read the sheet, so only share it with people who should see these records.

Use "Test connection" and compare the latest entry's "Sheet says" time with the time it was actually filled in. If they differ by an hour in summer, UTC is the right choice.
